# LPC1769

An LPC1769 board with the usual 16 KiB SD card bootloader. The browser cannot write to it over USB, so the card builds the firmware and offers it as a download, with the steps to copy it to the SD card:

![Build Klipper for an LPC1769 board](../../firmware/lpc1769/lpc1769.webflash.html){ type=iframe }

The TOML allows one method, `download`, and its instructions say what to do with the file: copy `klipper.bin` to the SD card as `firmware.bin` and power the board up. A board like this works in Firefox and Safari as well as in Chrome and Edge, since nothing is written over USB.
