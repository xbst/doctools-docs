# RP2040

Two RP2040 boards on USB. The first has no bootloader and is flashed through the chip's BOOTSEL ROM, over PICOBOOT or by writing a `.uf2` file to the drive the ROM shows:

![Flash Klipper to an RP2040 board](../../firmware/rp2040-usb/rp2040-usb.webflash.html){ type=iframe }

The second has Katapult in its first 16 KiB, so Klipper updates go through Katapult over USB, with PICOBOOT as the way back when Katapult is missing:

![Flash Klipper to an RP2040 board with Katapult](../../firmware/rp2040-katapult/rp2040-katapult.webflash.html){ type=iframe }

Things to try:

- **On the first card, pick UF2 drive on the Flash step.** Chrome or Edge asks for a folder: pick the `RPI-RP2` drive. In a page embedded from another origin the browser opens no folder picker, so the card offers the `.uf2` file as a download instead.
- **On the second card, compare the methods.** The card lists Katapult first, as the TOML's `[flash] methods` orders them, then PICOBOOT.

Boards with an IS25LP flash chip, such as the KUSBA, boot Klipper only with **Flash chip: GENERIC_03H with CLKDIV 4** under the low-level options. See [Configure](../site/configure.md).
