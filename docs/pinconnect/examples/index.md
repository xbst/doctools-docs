# Live examples

Every pinout on these pages is live: hover or tap a connector, open the connector list, or go fullscreen. Each one is generated from a TOML in this site's repository on every deploy, with the newest PinConnect from `master`, and embedded with [md-iframe](../../md-iframe/index.md). They are built exactly as [Publish on a docs site](../../guides/publishing.md) describes.

- [A real board](board.md): the OwlFC-Mini, in a custom theme that matches this site.
- [Connector gallery](connector-gallery.md): every bundled connector type, with sample pins.
- [Jumper settings](jumpers.md): pin headers whose jumper positions you can switch between.
- [Light and dark](light-dark.md): one pinout following the site's toggle, beside two pinned to a scheme.

The sources are in [`docs/pinouts/`](https://github.com/xbst/doctools-docs/tree/master/docs/pinouts), and each page links its TOML so you can open it in the [designer](https://pinconnect.isiks.tech).
